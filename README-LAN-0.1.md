# Vibe Chat — 安卓语音对讲

原生 Android 早期版本：耳机连接后自动播放新语音，长按悬浮按钮录音，松开发送，上滑取消。默认中文。最低 Android 8.0（API 26），目标 Android 15（API 35），不依赖 Google Play 服务。

## 用手机开始

1. 将 VibeChat-0.1.0.apk 发到安卓手机并安装。按系统提示允许当前文件管理器安装此 APK。
2. 先进入「单机回声体验」，允许麦克风和通知权限。按住底部按钮说话，松开后，回声助手将把真实录音原样返回。
3. 连接耳机，并打开「收到语音自动播放」。未连接耳机时，新语音保持未听，不会自动外放。
4. 开启「悬浮语音按钮」，按提示允许「显示在其他应用上层」。离开 App 后仍可按住按钮说话。拖动悬浮卡片的房间名称可以移动位置；点「隐藏」移除按钮。
5. 两人聊天：双方安装、连接同一 Wi-Fi 或手机热点；一人「创建房间」→「复制 / 分享邀请码」，另一人「加入房间」并粘贴完整邀请码。
6. 在 App 中「结束当前对讲」，或点常驻通知上的「结束对讲」，可关闭会话、录音服务与悬浮窗。

一个房间最多 8 个在线连接，房主也算其中一人。语音发给房间内所有在线成员。房主关闭会话后房间关闭。公共 Wi-Fi 的设备隔离可能阻止连接，可换用一台手机的热点。

## 首版的边界

- 这是可安装的独立 App，不接入微信。双方都需安装。
- 内置「创建房间」使用局域网，无需服务器、账号、付费服务。源码另附可自建的网络中转程序，但没有替你部署公网服务。
- 没有好友账号系统、离线消息投递、推送服务器、文本聊天和应用商店发布。
- 通用安卓接口检测的是音频耳机连接，不能判断是否实际佩戴。耳机留在耳边以外但保持连接时仍可能播放。
- 录音使用系统默认麦克风；首版不强制切到蓝牙耳机麦克风。
- 自动播放仅处理当前房间刚收到的消息。重新连接耳机不会突然播放旧消息；可到消息页手动听。
- 30 秒以内的单声道语音，16 kHz PCM，每秒约 32 KB。最近 60 条语音保存在 App 私有目录，卸载或清空记录会删除。
- 后台用用户主动开启的前台服务及常驻通知。麦克风只在按住时采集。系统杀进程后不会偷偷重启麦克风服务，需要重新打开 App。
- 厂商省电策略、锁屏、手机通话、音频焦点抢占和蓝牙切换仍需真机验证。不能承诺所有机型永久在线。
- 「已到达房间」表示房间中转端已收到，不表示所有成员已经听到。断网期间不自动保存到服务器；失败消息可明确重发到当前房间。
- APK 使用开发签名，适合安装体验，不是应用商店发行包。后续上架需要正式签名及权限申报。

## 数据与音频保护

每个房间使用随机的 256 位密钥。握手采用带角色区分的 HMAC-SHA256 挑战响应；语音采用 AES-256-GCM 加密与认证。邀请码包含密钥，只应分享给希望加入的人。所有持有房间密钥的成员均属同一信任组；本版本不提供个人身份验证、前向保密或独立的每人密钥。

自动播放先以静音预滚验证实际耳机输出路径，再开放声音；播放中监听音频路由变化、耳机移除、音频焦点及 AUDIO_BECOMING_NOISY。异常中断保留消息为未听。路由切换的极短瞬态仍取决于安卓及设备驱动，不能代替蓝牙真机测试。

不申请通讯录、位置、短信、通知读取、无障碍或全盘存储权限。不含统计、广告或第三方云 SDK；本机备份关闭。音频在 App 沙箱内存储，本版本没有额外的数据库静态加密。

## 开发与构建

原生 Java + Android 平台控件，不依赖第三方 Android 库。可在 Android Studio 中打开此目录。

标准 Gradle：

    ./gradlew :app:assembleDebug

要求 JDK 17、Android SDK Platform 35 / Build Tools 35.0.0。Gradle wrapper 固定为 8.11.1，Android Gradle Plugin 为 8.9.2。首次构建需要下载工具依赖。

亦可直接调用 Android SDK 构建，无需下载 Gradle：

    export JAVA_HOME=/path/to/jdk17
    export ANDROID_SDK_ROOT=/path/to/android-sdk
    python3 scripts/build.py

产物为 build/VibeChat-0.1.0.apk。脚本会在 build/debug.keystore 生成本机开发密钥；请保留密钥以便之后覆盖安装。不同密钥签出的 APK 不能直接覆盖安装，需要先卸载原版（会删除记录）。提供的源码包不含本次构建密钥。

协议与网络检查：

    sh scripts/test.sh

## 自建跨网络中转（可选）

需要一台双方可访问的服务器和 JDK 17。本交付没有创建账号、购买服务器、配置域名或开放你电脑的公网端口。

在服务器解压源码后：

    sh relay/run.sh YOUR_SERVER_HOST 45735

程序会输出一个新的房间邀请码。两个手机都选「加入房间」并输入该邀请码，即可经该中转进行在线语音收发。两台手机不需要在同一 Wi-Fi，但服务器的 TCP 45735 端口必须能被两台手机访问。语音内容和昵称由房间密钥加密；中转持有同一个房间密钥。

默认每次重启生成新密钥。若需要固定房间，可通过 VIBE_ROOM_KEY 环境变量提供一个 32 字节随机密钥的 URL-safe Base64（无填充）编码。不要使用短口令或公开邀请码。

中转是单房间原型：没有多租户、持久化、离线投递、监控、审计或运营管理。正式公网产品应增加账号认证、推送、滥用防护、可观测性、升级与密钥管理。

## 项目结构

- MainActivity.java：中文界面、权限入口、设置、消息列表。
- VoiceService.java：前台对讲会话、悬浮窗、消息队列、状态和重连。
- AudioEngine.java：录音、耳机识别、音频焦点、播放与路由保护。
- VibeApp.java：设置与本机最近 60 条语音。
- core/：可直接在 JVM 上测试的加密、协议和双向房间传输。
- relay/：可选独立中转。
- tests/：真实 TCP 收发、鉴权和协议边界检查。
- VALIDATION.md：验证范围与尚需真机检查的项目。

安卓实现参考：[前台服务类型](https://developer.android.com/develop/background-work/services/fgs/service-types)、[后台启动限制](https://developer.android.com/develop/background-work/services/fgs/restrictions-bg-start)、[音频路由 API](https://developer.android.com/reference/android/media/AudioRouting)。
