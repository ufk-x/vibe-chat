# Vibe Chat

可自托管的 Android 语音聊天和对讲应用，支持 Android 8.0 及以上。两人可以扫码加好友、建群、发送文字和语音。开启对讲后支持耳机自动播放及悬浮窗按住回复。可选阿里云百炼转写。

- **从零搭建**：[完整部署指南](deploy/README.md)
- **交给 AI 部署**：[可直接复制的任务说明](deploy/AI-DEPLOY.md)
- **接入语音转写**：[阿里云百炼配置](deploy/ASR.md)

原部署使用阿里云中国香港轻量应用服务器、Ubuntu 24.04、Node.js 24、SQLite 与 Caddy。每个复刻实例用自己的域名、账号库和 APK 签名。当前源码基于客户端 0.6.8（versionCode 30）。

0.5.0 新增默认语音转文字：

- 语音消息先送达、可立即收听，下面先显示「正在转文字…」，随后自动显示识别结果，支持长按选择和复制。发送者与接收者都能看到，私聊、群聊及房间一致。
- 聊天列表显示语音识别内容摘要。同一句语音仅由服务器识别一次，群内共享结果。识别结果更新不会产生新消息、增加未读数或再次自动播放语音。
- 首次打开旧会话时为当前显示的最近 50 条消息补充识别；后台不会扫描全部历史。无清晰人声显示相应提示；识别失败只影响文字，点文字提示重试不会重发语音。原语音发送状态修复继续保留。
- 采用阿里云百炼北京业务空间的 `qwen3-asr-flash`。API Key 仅保存在自有服务器，语音通过 HTTPS 发送给阿里云识别；文字沿用原会话权限和消息保留期限。当前没有端到端加密。
- 默认限制每天 1 小时、每月 30 小时的识别请求音频，包含失败及重试的预留用量；按 2026-11-07 官方单价约 0.792 元/小时，月上限约 23.76 元，云端实际账单为准。超限只暂缓文字，语音仍可收听。
- 参考 [Type4Me 的批量识别设计](https://github.com/joewongjc/type4me/blob/f21339e214d65e9bd4d191ff5136513902e7473b/Sources/Type4Me/ASR/BufferedBatchASRClient.swift)，将录音包装为 16 kHz 单声道 WAV 后异步提交；实现为适合多人聊天的服务器持久队列，未直接复制 Swift 代码。

识别服务配置见 `deploy/ASR.md`。已安装 0.3.0 或更新版本可在「我 → 检查更新」覆盖升级。

## 已实现

- 账号注册、登录、修改昵称、修改密码、退出；密码使用 scrypt，手机登录令牌通过 Android Keystore 加密保存。
- 好友二维码和好友申请确认；好友私聊。
- 群聊、多人房间；群主可以从好友中拉人、生成/重置二维码、查看成员、解散；普通成员可退出。
- 相机扫码、相册识别、粘贴邀请。二维码不含密码，个人码 30 天有效，群/房间码 7 天有效。不同服务器的二维码不会自动携带登录令牌去访问。
- 文字与最长 30 秒语音，服务器保存离线消息；当前聊天界面显示最近 50 条。服务器保留最近 30 天消息。
- 手动开启对讲后，连接蓝牙/有线/USB 耳机时自动播放新语音；关闭开关即可停止自动播放。登录时不补播历史消息，超过 60 秒的延迟消息留待手动播放。
- 自动播放覆盖所有已加入的会话；悬浮按钮显示最近播放的会话并向其回复。打开其他会话会切换回复对象；聊天页的录音始终发给打开的会话。
- 悬浮按钮按住录音、松开发送、上滑取消；录音开始时锁定接收会话。发送失败的语音在本机保留并可向原会话重试，服务器按消息编号去重。
- 默认不连接耳机时不会自动外放；可以在对讲页显式开启无耳机自动播放。手动点击直接按系统媒体路由播放。耳机断开、音频焦点丢失时停止当前播放。
- HTTPS、SQLite 持久化、独立低权限服务账号、开机启动、异常重启、每日数据库备份。

## 使用

1. 安装 APK，输入账号、至少 10 位密码、昵称，点“创建个人账号”。之后直接登录。
2. “好友 → 我的好友二维码”展示给朋友；朋友扫一扫并申请，通过后可聊天。
3. “聊天 → 右上角＋”创建群聊或房间。会话右上角“•••”可以拉好友、展示二维码和查看成员。
4. 进入会话或“对讲”页开启对讲，授予麦克风及通知权限；连接耳机并打开自动播放。
5. 打开悬浮按钮开关，在系统页面授予“显示在其他应用上层”。按钮仅在对讲开启时显示；上方标题是回复对象。左侧麦克风按住录音，其他区域可拖动；右侧「−」收起、轻点小圆点展开；拖动时底部出现「×」，拖到上面松手即可隐藏。
6. 需要锁屏/后台持续使用时，在系统的应用电池设置中允许后台运行。结束对讲可从 App 或常驻通知操作。

## 已知边界

这是可安装、自托管的初版，不具备微信的全部功能。没有手机号/短信找回密码、视频通话、图片文件聊天、好友搜索、拉黑、群主转让或厂商离线推送。APK 为本地开发签名包，尚未上架应用商店。账户密码请自行记好。

耳机“已连接”不等于“已佩戴”，普通安卓接口不能统一检测所有品牌耳机是否入耳。后台运行受厂商省电策略及系统 Doze 影响；应用被强行停止或被系统杀掉时不会继续实时播放，下次打开会同步离线消息。持续对讲会增加耗电。

公网语音通过 HTTPS 传输，服务端和其备份可读取消息，当前不提供端到端加密。新成员只能读取加入后的消息；退出成员无法继续通过接口读取该会话。默认试用上限 100 个账号、每群/房间 50 人、每用户 100 个会话，SQLite 数据容量上限约 2 GiB；需要扩容时再调整。备份保存在同一服务器，不是异地容灾。

## 目录

- `app/`：Android Java 应用与 ZXing 3.5.3 二维码依赖及许可证。
- `server/`：Node.js 24 服务端，无第三方运行时依赖；SQLite 保存账号、权限、消息和语音。
- `deploy/`：Ubuntu 安装、systemd 服务与每日备份配置。
- `scripts/build.py`：直接使用 JDK 17 和 Android SDK 35 构建 APK。
- `tests/`、`relay/`：0.1 版局域网协议测试与独立中继，保留单机回声体验入口。

## 在本机检查代码

在 Android Studio 的 SDK Manager 安装 Android SDK Platform 35、Build-Tools 35.0.0 和 Platform-Tools。使用 JDK 17、Python 3.9+ 和 Node.js 24 LTS。

```sh
# 先将 JAVA_HOME 和 ANDROID_SDK_ROOT 指向本机安装目录。
export PATH="$JAVA_HOME/bin:$PATH"
npm test --prefix server
sh scripts/test.sh
VIBE_ORIGIN=https://vibe.example.com python3 scripts/build.py
```

输出 `build/VibeChat-0.6.8.apk`。示例域名是占位值，需换成自己的 HTTPS 域名才有公网聊天和在线更新。也可在 Android Studio 打开工程，或以同一个 `VIBE_ORIGIN` 执行 `./gradlew assembleDebug` 作本地开发。它和上面的 Python 脚本使用各自的调试签名。分发 APK、维护在线更新或保留旧安装数据，按部署指南固定使用同一签名密钥。

完整自托管流程包括购买或选用服务器、DNS 和 TLS、服务安装、签名、发布及验证。见 [部署指南](deploy/README.md)。历史实测见 [验证记录](VALIDATION.md)，旧版局域网说明见 [README-LAN-0.1.md](README-LAN-0.1.md)。
